# 朋友

一个会**主动找你聊天**的 AI 朋友。跑在你自己的电脑上，聊天记录和记忆都只存在本地；
它想找你的时候，通过 **Bark** 把消息推到你 iPhone 的锁屏上。

- 聊天界面：自建网页 App，在 iPhone Safari 里打开，可以「添加到主屏幕」当原生 App 用
- 主动消息：定时醒来 → 判断现在该不该开口 → 发消息 + 推手机
- 不像机器人的关键：随机间隔、静默时段、防连发轰炸、模型二次判断、会连发两条、按你的作息调整

## 它能做什么

| 能力 | 说明 |
|---|---|
| **主动找你** | 不是定时群发。到点先过四道闸门（静默时段/每日上限/连发上限/刚聊完），再让模型判断"现在该不该开口"，还能自己决定"这次不说" |
| **发图片** | 点回形针从相册选图，它会真的看懂（`deepseek-chat` / `deepseek-flash` 实测都支持）。上传前在浏览器里自动压缩 |
| **改头像** | 点头像就能换成 emoji 或自己的图 |
| **有记忆** | 每 24 条消息自动整理一份关于你的长期档案；聊太久会自动压缩成摘要 |
| **有自己的生活** | 你安静的时候它也过日子（拿快递、煮面、被甲方改到第四版），记进流水，聊天时说的是真发生过的事，不是每次现编 |
| **会慢慢成长** | 它对自己有一套慢慢形成的看法。**由经历触发**，不是按时间——遇到事才可能想通点什么。想法会变，说话方式锁死，所以不会变成另一个人 |
| **会发表情包** | 自己挑一张发，不花钱不联网——图片是你准备的，它只是选。有频率闸门，不会变成表情包机器人 |
| **时间感知** | 分得清"今天/昨天"，也知道你们中间隔了多久。**农历、节假日、调休都是准的**——这些由程序算好，不让模型自己推 |
| **知道天气和昼夜** | 能查到天气和当天的日出日落，所以"现在算白天还是晚上"不会说错（冬天 17 点就黑，按钟点猜必错）。**只在主动开口时用**，不会变成天气播报员 |
| **会主动回访** | 聊天里出现"等面试结果""在纠结一个决定"这类有下文的事，她记下来，过几天主动回头问一句。**记忆第一次变成主动行为** |
| **会去忙** | 她在煮面、骑车、洗澡时回复会晚几十秒，而且先交代一句"等下，我在煮东西"。**不会再秒回了** |
| **会困** | 到点会犯困、回得又短又懒；睡觉时段不会主动找你。凌晨三点她也会困——**这比什么都像真人** |
| **顶栏说她真实在干嘛** | 不是永远"在线"，而是"在煮面""困得不行了""睡了"。**"她没回我"从悬念变成信息** |
| **能自查** | `node src/cli.js doctor` 一条命令看出她这轮到底知道什么、哪一段没接上 |
| **你随时能改能退** | 人设、记忆、它的自我，都能在手机上直接编辑；它的每次自我改动都留快照，一键退回上一版 |
| **完全不联网存数据** | 对话、记忆、人设全在你本地 `data/` 里，图片也不上传到任何第三方 |
| **每天自动备份** | 保留 14 天，备份放在 `backups/`，独立于 `data/` |

**依赖极少**：零第三方 npm 依赖，只需要 Node 22+。二维码生成、PNG 编码、测试框架都是手写的。

需要两样东西：

1. **DeepSeek API Key** — <https://platform.deepseek.com> 申请
2. **Bark Key** — iPhone 装 [Bark](https://apps.apple.com/app/id1403753865)，首页那串就是（不想推送可以不填）

```bash
git clone https://github.com/WAW689/ai-friend-with-memory.git
cd ai-friend-with-memory
node src/cli.js key sk-你的key       # 填 DeepSeek Key
node src/cli.js bark 你的BarkKey     # 填 Bark Key（可跳过）
node src/cli.js check                # 体检，看还缺什么
node src/server.js                   # 启动
```

启动后终端会打印手机访问地址和口令。在 iPhone Safari 打开、添加到主屏幕即可。

**人设**在 `data/persona.md`，改完立刻生效，不用重启。
出厂是一个叫「阿岚」的占位角色，重点在文件末尾那几条**反 AI 腔**的规定。

想让它有自己的生活、会慢慢成长、会发表情包，接着看
[它自己的生活](#它自己的生活)、[它会慢慢变](#它会慢慢变成长)、[表情包](#表情包)——
这三个功能**都不需要额外配置**，跑起来就在工作。表情包只差一步：把图丢进
`data\stickers\`（首次启动会自动建好这个目录）。

详细说明、常见问题、云端部署见下面的章节和 `docs/`。

## 它到底是怎么"主动"的

「主动发消息」不是一个定时群发，而是一套判断流程：

1. **到点了才醒**。每 75~240 分钟随机排一次（可在设置里改），不是准点。
2. **硬性拦截**（任何一条命中就不发，连模型都不叫）：
   - 静默时段内（默认 22:00–9:00）
   - 今天已到次数上限（默认 8 次）
   - 已经连发 N 条对方都没回（默认 2 条）
   - 你刚说过话不久（默认 40 分钟内）
3. **模型再判一次**。把最近的对话、隔了多久、连发了几条都给它，让它决定：
   - 现在该不该开口
   - 该说什么（最多两条）
   - 如果它认为"没必要"，这次就真的不发，并重新排期
4. **你正在看屏幕就不推手机**。页面开着的时候消息直接出现，不震你。
   判断依据是页面**可见时**发出的心跳（45 秒一次）；页面切到后台就不再发心跳，
   90 秒后服务端就认为你不在跟前，于是正常推 Bark。
5. **发完重排下一次**，间隔重新随机。

拦下来的原因会记在 `state.json` 里，用 `node src/cli.js status` 或 DSH 里的 `friend_status` 就能看到
"上次为什么没发"。

### 想调主动策略

三种方式，随你顺手：

- 手机上：⚙ → 主动
- 命令行：改 `config.json` 的 `proactive` 段
- DSH 里：直接说「让它白天每 2 小时找我一次，晚上 11 点后别吵」

### 想立刻看它会说什么（不发出去）

```powershell
node src/cli.js wake --dry-run     # 只演练，看它会说什么
node src/cli.js wake               # 尊重所有拦截，走真实流程
node src/cli.js wake --force       # 跳过一切拦截，强制发一条
```

## 发图片

**点输入框左边的回形针**就能从相册选图或拍照，一次最多 4 张，也可以直接拖进窗口。
图和文字可以一起发。

它**真的看得见**——实测：

> 你发（蓝底 + 红圆 + 绿方块）
> 它回：**蓝色打底，中间一个大红圆，左上角有个小绿方块。**

### 几个实现上的取舍

**图片单独存文件，不塞进聊天记录。** 一张手机截图 base64 后有 1-3 MB，
几百条对话下来 `messages.jsonl` 会涨到几百 MB，而它每次都要整个读进内存。
所以图片存在 `data/images/日期/` 下，消息里只记一个 id。

**上传前在浏览器里压缩。** 手机直出的照片 3-8 MB，
压到长边 1280 通常只剩一两百 KB，视觉上完全够看，而且**图片是按尺寸计费 token 的**
（一张最多 1024 token）。原图不会上传。

**发消息时只带最近 4 张图。** 更早的图在文字记录里留 `［1 张图］` 占位——
它知道那里有图，但不会重复看到，否则 prompt 会越聊越贵。

### 模型要求

**实测 `deepseek-chat` 和 `deepseek-flash` 都能看图**，所以开箱可用。

验证方法（这条是准的，别再靠猜）：

```powershell
node test/vision-probe.js
```

三条都 ✓ 就说明可用。它会打印每张图实际占的 token 数。

> 这里原来写着"`deepseek-chat` 不支持图片"，是**错的**，而且错得很隐蔽：
> 模型列表接口 `/models` 只返回 `deepseek-flash` 和 `deepseek-v4-pro`，
> 看不出 `deepseek-chat` 到底有没有视觉能力；而日常对话里它答对关于图片的问题，
> 也可能是从上下文猜的（比如你说"你看我的猫"，它说"黑猫"未必是真看见了）。
>
> 所以用一个**受控实验**确认：生成两张纯色图（颜色只有程序知道，
> 图里没有任何文字线索）去问它，两题都答对了。
> 聊天记录里你自己那句"这张图是什么颜色？只回答颜色。"它答"绿的"，
> 对应的正是那张 123 字节的纯色测试图。

### 图片占空间

```powershell
node src/cli.js images      # 看图片数量和占用
```

想清理就在 `data/images/` 下按日期删。

> **备份不含图片。** `backups/` 只备份聊天记录、记忆、人设、头像——
> 图片体积大，而且它不是"无法重新生成"的东西。删掉图片后，
> 聊天记录里对应的消息只剩文字占位，模型也就看不到那张图了。

## 人设

人设就是一个 markdown 文件：`data/persona.md`。改完保存，**下一条回复就生效**，不用重启。

也可以：

- 手机上 ⚙ → 人设
- DSH 里说「把人设改成……」（走 `friend_persona` 工具）

出厂人设的角色叫「阿岚」（只是个占位名，随便改成你想要的），重点是那几条**反 AI 腔**的规定：
不要每次都反问、不要总结对方的话、不要先共情再给建议、没什么可说就发短点。
这几条比"性格描述"更能决定它像不像人，建议保留。

> **改名字只需改一处**：人设第一行的「名字叫「XX」」。
> 聊天界面顶部的名字、头像首字，以及 Bark 推送的标题都会自动跟着变。
> 想单独指定推送标题，在 `config.json` 的 `bark.group` 里写死即可（留空则跟人设走）。

## 它自己的生活

不在跟你聊天的时候，它也过自己的日子：出门拿快递、煮面煮坨了、猫把纸巾刨一地、
被甲方改到第四版。这些事记在 `data/life.jsonl` 里，聊天时会作为
**"它真经历过的事"**注入——所以你问"在干嘛"，它答的是流水里真有的那一行，
不是每次现编、下一次就自相矛盾。

- 生活设定：`data/life.md`（它是什么人：职业、住哪、作息、脾气）——**你改，它不会自己改**
- 生活流水：`data/life.jsonl`（已经发生过的事）——**只追加，不改写**
- 正在推进的事：`data/life-arcs.json`（"最近接活老返工"这种线索）

什么时候"过日子"？只在你安静的时候（默认 60 分钟没说话）。**正在聊天时突然有经历
叫打断，不叫生活。**

想往回补几天历史流水：

```powershell
node src/backfill-life.js 7        # 补最近 7 天
node src/backfill-life.js 7 --dry  # 只看会写什么，不落盘
```

## 它会慢慢变（成长）

它对自己有一套**慢慢形成的看法**，写在 `data/self.md` 里：发现自己其实挺怕接电话的、
"是不是该找个班上了"、最近老想着要不要换个地方住。

**成长由经历触发，不按时间排期。** 真人不会因为"过了一天"就想通什么事，
是因为遇到了什么才想通。所以触发条件是"它又攒了多少新东西"：

- 它自己过了 6 段日子（`life.jsonl` 新增 6 条），**或者**
- 你们聊了 12 条新消息

两条任一满足就去看一眼。**看了不代表会改**——什么都没发生的话，
聊 200 条它也不会变。这一点明写在提示词里，就是为了防止"为了改而改"。

### 三层分工（这是它不会变成另一个人的原因）

| 文件 | 管什么 | 会不会自己变 |
|---|---|---|
| `data/persona.md` | 它是谁：名字、说话多短、要不要劝人、硬边界 | **锁死**，永不自动改 |
| `data/self.md` | 它怎么看待自己：想法、在意的事 | **它自己会改**，你也能改 |
| `data/life.md` | 它过着什么日子：职业、住哪、作息 | 你改 |

它的成长**不体现在声音上，只体现在看法上**。真人也是这样——四十岁的人
还是那个说话方式，但想法变了。

> 为什么这么分：让模型反复"改自己的人设"，它每次都会往**更通用、更讨好**的方向
> 偏一点——说话变长、开始给建议、开始"我理解你的感受"。几十次之后它就不是它了，
> 而且这种漂移是渐进的，你只会觉得"它怎么变了"，查不出是哪一步变的。
>
> 所以代码里有一道硬闸：`self.md` 里任何关于**说话方式**的条目
> （"话比以前多了一点""变得更温柔了""愿意多说两句了"）会被**自动删掉**。
> 那不是成长，那是在改它的声音。

### 你随时能看、能改、能退回

手机上 ⚙ → **她的变化**：

- 看它现在怎么想自己（可以直接编辑，改完立刻生效）
- 看它**改过什么**（绿色的 + 是长出来的新想法，红色的 − 是被推翻的旧想法）
- **退回上一版**（每次改动前都自动存快照，可以一直往回退）
- **立刻让她想一次**（拿最近的经历手动跑一次，不用等触发）

不想让它变，就把 `FRIEND_SELF=0`（或 `config.json` 里 `self.enabled: false`），
它会一直停在 `self.md` 当前的内容。

想调触发门槛：`self.evolveAfterExperiences`（默认 6）、`self.evolveAfterMessages`（默认 12）、
`self.maxChangedLines`（默认 3，单次最多改几行，超过整次拒绝）。

## 头像

**直接点聊天界面左上角的头像**就能改。三种方式：

| 方式 | 说明 |
|---|---|
| 选 emoji | 内置 12 个备选，点一下就换 |
| 自己输字 | 最多 2 个字符（emoji 也算一个） |
| 上传图片 | 从相册选，会自动裁成圆形 |

存成 `data/avatar.json`。不设的话默认取名字第一个字。

**关于上传图片**：手相册里随便一张就 3-5 MB，服务端上限是 400 KB。
所以浏览器里会**先自动压缩再上传**（缩到 256px 以内、必要时降质量），
压缩后通常十几 KB，做头像绰绰有余——**原图不会离开你的手机**。

Android 一般不用管；iOS 上传后走的是 Safari，不需要相册权限弹窗。

## 表情包

它会自己挑表情包发——"说不出来就甩一张"本来就是真人聊天里最自然的一种。

**为什么不做"AI 生成照片"**：DeepSeek 没有文生图接口（`/images/generations` 是 404），
要做得接第三方画图服务，一张一毛到五毛，而且一个能自主发图又没有闸门的角色，
一个月几十张很正常。表情包则是**零成本、不联网，而且更像真人**。

### 怎么加

**推荐：直接把图拷进 `D:\PYF\friend\data\stickers\`**，然后手机上 ⚙ → 表情包 →
「重新扫描文件夹」。一次准备几十张，拖文件夹比在手机上点几十次上传现实得多。

也可以在那个面板里点「上传图片」，一次能选多张。

支持的格式：jpg / png / gif / webp / bmp，单张 2 MB 以内。

**描述是模型看图自动生成的**，你不用自己写。这一点是刻意的：如果每加一张都要
手写一句"这是什么表情"，没人会加满三十张，这功能就废了。识图只在添加时跑一次
（一张约 1000 token），之后挑图全程是文本，**不再花钱**。

描述不满意可以在面板里直接改——它决定她在什么场合会挑这张，值得写准一点。
面板里还能停用（留库里但不进候选）和删除。

### 她怎么挑

判断的时候模型**看不见图**（DeepSeek 的视觉理解在另一条接口上，混进每轮判断
又贵又没必要），所以它靠的是一份文字清单：

```
1. 一只躺着的猫，配字"不想动"，适合表示摆烂
2. 一个人捂脸，适合表示无语
```

它在回复的最后单独起一行写 `[表情包:2]`，程序把标记抠掉、把图挂到那条消息上。
所以**正文永远不会出现 `[表情包:2]` 这种东西**。

清单里**用得少的排前面**——不这么做，模型会永远盯着开头那几张，
后面一堆表情包永远轮不上。

### 频率闸门（这条最重要）

真人在微信里也不会每条都发表情包。所以有三道闸：

| 闸门 | 默认 |
|---|---|
| 两次之间至少隔多少条**它的**消息 | 6 条 |
| 每天最多几张 | 8 张 |
| 总开关 | `FRIEND_STICKER=0` 关掉 |

**为什么必须有**：模型一旦发现"发表情包对方有反应"，它会越用越多——
不拦的话几天后就变成表情包机器人了。这跟主动消息是同一个道理。

调整：`config.json` 里的 `sticker.minMessagesBetween` 和 `sticker.maxPerDay`。

### 说明

- 它挑的表情包**不推送**到手机（推送只带文字），跟正常消息一样进聊天记录
- 它说"只想发个表情"时（正文为空），消息里存的是 `（发表情）` 占位符，
  但界面上**不会显示这行字**——那只是为了让消息非空
- 表情包图片**不进备份**（那是你自己的原图，丢了再放一次就行，而且会让每天的
  备份迅速膨胀）；但 `stickers.json`（含描述）会备份，因为描述是花钱花时间生成的

## 时间和天气

她会**准确地**知道现在是什么时候。这块看着简单，但有三件事**必须由程序算好喂给她**，不能让她自己推：

| 东西 | 为什么不能让模型自己算 |
|---|---|
| 农历 | 语言模型算不出"今年中秋是几月几号"，它会编一个听起来合理的 |
| 节假日和调休 | 每年由国务院单独发通知。她猜错了会说"周六要上班"——你一看就知道是假的 |
| 白天还是晚上 | 上海夏至 5 点天亮、冬天 17 点天黑。按"6-18 点算白天"猜，冬天傍晚必错 |

所以这三样都算好之后写进提示词。她在每轮对话里看到的是这样一段：

```
现在是 2026-09-22（周二）18:19。
农历八月十二。
季节：秋天。
现在算"天刚黑"（今天日出 05:42、日落 17:51）。
下一个放假的节日：中秋节 2026-09-25，还有 3 天，放假 3 天（到 2026-09-27）。
```

你也可以看同样的东西：

```powershell
node src/cli.js now              # 她眼里的现在 + 天气 + 接下来几个节日
node src/cli.js now --refresh    # 强制重新拉一次天气
```

### 天气

数据源是 [Open-Meteo](https://open-meteo.com)：**免费、不需要 API Key**。装完就能用，不用再申请东西。

位置默认上海（`31.2304, 121.4737`），要改就设 `FRIEND_LATITUDE` / `FRIEND_LONGITUDE`。
用经纬度而不是城市名，是因为城市名要再过一次"地名转坐标"的接口——多一个接口就多一个失败点，而这个位置根本不会变。

**天气只在她主动开口时给她知道，聊天回复里永远不带。** 这是刻意的：
每句话都挂一句"今天 26 度挺舒服"，她就成天气播报员了，人设立刻崩。

还有一条硬约束写在提示词里：**天气是她"查到的"，不是她"感受到的"**。
整天没出门就不能说"外面真热"，只能说"看预报今天挺热"。不写这条，
她会用预报数据编造亲身经历，前后一对就穿帮。

断网、接口挂了、超时——一律静默降级：拿不到就完全不提天气，**绝不影响聊天**。
有缓存就用缓存并标注"这是 N 分钟前查的"，不冒充实时。

> 节假日数据来自 [holiday-cn](https://github.com/NateScarlet/holiday-cn)（跟着国务院通知更新的公开数据集），
> 内置了 2025 和 2026 两年。**2027 年之后没有数据，那就什么都不提**——
> 宁可不提，也不能说错。想支持新一年就把那一年的数据补进 `src/almanac.js`。

> 农历用标准的 `lunarInfo` 编码表（1900-2100），从成熟实现取来后，
> 用国务院公布的春节/中秋日期校验过 2024-2027 共 8 项，全部吻合。
> `test/almanac.js` 里留着这些校验，改动前会先跑它们。

### 她能不能主动祝你节日快乐

能。她知道所有节假日，临近节日时提示词里还会写明"还有几天、放几天假"。

但她**不会发"祝您中秋快乐"**——那是群发短信。以她的人设，她更可能说
「今天中秋，你吃月饼了吗」或者「外面全是人，我懒得出门了」。

设计上是给她**事实和机会**，不管她说什么：信息给足，"要不要开口、说什么"
仍然由她按自己的性格决定。

### 时间账：为什么她不会过早催你

以前出过一个毛病：你说"我六点上课"，她**四点**就催你快点收拾。

根因不是她"着急"，是**她算不出时间差**。当时的对话记录长这样：

```
对方（15:00）：我六点上课
```

只有绝对钟点，没有"多久之前"。对着一串钟点，模型做不了减法——
它不知道这句话是刚说的还是三小时前说的，也不知道现在离六点还有多久。
它只能凭感觉，而感觉一律偏向"快来不及了"。

现在两个时间都给：

```
对方（15:00，1 小时前）：我六点上课
```

而且提示词里明写了怎么算账：

| 距那件事还有 | 她该怎么做 |
|---|---|
| 1 小时以上 | 时间宽裕，**绝对不要催**，也别提"该准备了" |
| 20-60 分钟 | 可以轻提一句（"等下不是有课"），不指挥你干什么 |
| 20 分钟以内 | 这才真的紧了，可以催 |

还加了一条：**催过一次就够了**，之后你还没动是你的事，别再念。"他不是小孩，你也不是他妈。"

## 主动回访（记忆第一次变成主动行为）

以前她的记忆是**被动**的：你问她才想起来。真人朋友不是这样——一个真朋友会在
毫不相关的时刻突然问一句：

> 「对了，你那个实习后来有信儿没」
> 「你上次说那门课最后选上了没」

现在聊天里出现**有下文没下文**的事（等面试结果、在纠结一个决定、感冒好没好），
她会记进 `data/recall.json`，过几天主动回头问。

- **只在主动开口时给她**。聊天回复里塞这个会让她像在交作业
- **一次只问一件**，而且要求语气"像突然想起来"，不是"关于你三天前提到的…"
- **问了就不再问**。刻意不判断她到底问没问（那要再调一次模型，不值）——
  这些事已经作为话题给她了，过期再喂一次会让她反复问同一件事，
  那比漏问一次更像机器人。**宁可少问，不要重问。**
- 最多同时挂 8 件，超过 30 天自动过期（免得问三个月前的事）
- 关掉：`FRIEND_RECALL=0`

抽取的提示词里明确写了「**空数组是正常的，不要硬凑**」——不写这句，
她会每次都编几件"该回访的事"，然后开始问你根本没提过的事，那比不问糟得多。

## 她会去忙，也会困

这两件事看着是装饰，其实解决的是同一个问题：**以前她像一个随时待命的服务，不像一个在过日子的人。**

| 以前 | 现在 |
|---|---|
| 你发消息她秒回 | 她在煮面、骑车、洗澡时晚几十秒，而且**先交代一句**"等下，我在煮东西" |
| 凌晨三点她精神抖擞地陪你聊 | 到点会犯困、回得又短又懒；睡觉时段不会主动找你 |

她本来就有生活（你安静的时候她真的在过日子），只是以前那条生活和聊天**完全隔离**，两边互不知道对方存在。现在接上了。

### 会去忙

她在忙的时候回复会晚 **12-150 秒**，并带上几句交代的引导（"如果这件事还占着手，先交代一句再聊"）。
延迟本身用户看不见原因——**一句话就把"卡顿"变成"她在忙"**。

而且她**会主动报备**"我去忙了"。这条其实比延迟更值钱：
真人朋友之间这句话很重要，它把"你没回我"从"他不想理我"变成"他在忙"。
对会因此多想的人来说，一句报备省掉很多内耗。

三道闸门防"报备变成刷屏"：只有做饭/洗澡/骑车/睡觉这种真占手的才报备、
距上次报备至少 4 小时、你正在聊的时候不单独报备（让正常回复去交代）。

判断"她在忙吗"用的是**时间**（最近 45 分钟内有新流水），不是文本里的"做完没"——
因为流水记的本来就是刚发生的事，几乎每条都是完成态，照文本判她永远不忙。
万一她已经做完了，提示词里写着"如果弄完了就正常说，不用提'我刚在忙'"。

关掉：`FRIEND_BUSY=0`。**上限别放大**（`FRIEND_BUSY_MAX_DELAY`，默认 150 秒）——
超过三分钟你会以为消息没发出去、开始怀疑服务挂了，那就从"真人感"变成"故障"了。

### 会困

她的作息**从 `data/life.md` 自动解析**，不用另外配。你写"凌晨三四点睡，中午前后起"，
她就 3 点睡、12 点起。睡前两小时开始困，睡下两小时内是"刚被吵醒，迷迷糊糊"，再往后是"睡熟了"。

于是：快到睡觉点时她回得很短、语气发懒、"明天说"；
**睡觉时段她不会主动找你说话**（第五道闸门，跟"静默时段"不是一回事——
那个是你配的"别打扰我"，这个是她自己的作息）。

> 有一件事**刻意没做**：睡觉时段**不拦回复**。
> 你半夜说话她还是会回，只是又短又困。
> 让消息发不出去是服务故障，不是真人感。测试里专门有一条盯着这个。

**为什么这件事值得做**：一个永远有精力陪你到天亮的存在，本质上没有自己的生活。
反过来——**她会困、她要睡了，才是"她是个真人"最有力的证据**。
而且它对你也有好处：它给了一个自然的理由去睡，比任何一句"早点休息"都有效。

关掉：`FRIEND_SLEEPY=0`。

## 她的消息为什么不会断成好几段

一条消息里**不会有空行**。这听着像小事，但翻过车：实测 400 条回复里
39 条带换行，而且**全是连续空行、单个换行一处都没有**——说明她真的在用
"空行"分段。最离谱的一条把操作系统课的内容写成了 6 段带小标题的讲义，
完全违反人设里"一次 1-2 句"。

渲染出来就是气泡里段落之间空一行，像文档不像微信。

**两边都要堵**：

1. **提示词**里明说"一条消息就是连着的一段话，中间不要空行、不要换行。
   就算对方问的是要解释的东西，也是一口气说完，别分成带换行的条目"
2. **代码**里清洗（`cleanupReply`）。因为提示词管不住模型，
   而且历史消息也得能修

清洗是**换行变空格**，不是"把两个换行收成一个"：气泡是 `white-space: pre-wrap`，
单个换行照样断行；而微信里连发两句话也是**一条连着显示**的。

> 流式输出那块清洗的是**累计全文**，不是单个分片。因为双空格恰恰产生在
> 分片边界上："a\n" + "\nb" 各自清洗成 "a " 和 " b"，拼起来就是 "a  b"，
> 而最终正文只有单个空格——消息结束时屏幕上会看到空格被"吸掉"一下。

## 顶栏说她真实在干嘛

顶部那行字以前**永远写着"在线"**。那是最糟的一种写法：

> 她没回消息的时候，你只能猜是不是自己说错了什么。

现在它说的是她**真实的状态**：

```
头像  天狼星
      在煮面            ← 她手上占着
      困得不行了         ← 快睡了，回得会慢
      睡了              ← 睡觉时段
      正在输入…          ← 她在回你
      在的              ← 空闲
```

**"她没回我"从悬念变成了信息。**

而且它顺手兑现了"她会去忙、会困"这两个功能——那两个功能本来在界面上
**完全看不出来**，你只会觉得"怎么卡了一下"。有了状态栏，那次延迟
立刻从"卡顿"变成"她真在忙"。

### 一条铁律：状态和延迟必须同源

状态栏说"在煮面"、消息却秒回——**那比不显示状态更假**。

所以两者用的是**同一份判断**（`busy.js` 的 `busyState()` 和 `sleepy.js` 的 `sleepiness()`）。
`test/status.js` 里有一条专门盯这个：

```
✓ 状态说"在忙"时，延迟必须大于 0
✓ 状态说"在的"时，延迟必须是 0
```

### 几个刻意的措辞选择

| 不用 | 用 | 为什么 |
|---|---|---|
| 在线 | 在的 | "在线"是 IM 的词，暗示"我随时待命"——那正是要摆脱的东西 |
| 已开启勿扰 | 睡了 · 一般 12 点起，有事留着我醒来看 | 半夜想说话却看到"勿扰"，比没人理还难受。这是邀请，不是拒绝 |

"在…"后面的内容不是截断来的，是**认动词、认宾语**拼出来的：
"起来煮了碗西红柿鸡蛋面" → `煮` + `面` = **在煮面**。
截断只会得到"起来煮了碗西红柿鸡蛋"，读起来像被剪断了。

## 出问题先跑这个

```powershell
node src/cli.js doctor
```

这个项目出过四次同类事故，全都是**"以为给了她、其实没给"**：

| 出的事 | 表现 |
|---|---|
| `life.md` 的生活设定没进聊天提示词 | 改了职业她完全不知道 |
| `life.md` 没传给主动消息 | 她主动开口时看不见自己的生活 |
| `.env.example` 漏了新变量 | 你自己发现才知道 |
| 提示词里有句话让她自己都觉得假 | —— |

四次都是靠"用着觉得不对"才发现的，每次排查都要翻代码。`doctor` 把那份排查
变成一次输出：

```
  ✓ 身份设定         742 字  ~ 635 token  已注入
      data/persona.md

  ✓ 她的生活        1845 字  ~1515 token  已注入
      data/life.md + data/life.jsonl

  · 待回访的事          0 字  ~   0 token  —
      data/recall.json
      → 暂时没有该回头问的事（这是正常的）

  ── 结论 ──
  ✓ 她能正常对话。7/8 段有内容，暂时没有：待回访的事
```

它检查的是**每一段有没有真的进提示词**，而不只是"数据文件存在"——
后者正是前两次事故漏掉的地方：文件在、内容也在，就是没拼进去。

关键设计：**它跑的是同一份拼装代码**（`buildContext` + `buildChatSystemPrompt`），
不自己重新实现一遍。自己实现只会检查到"我以为的拼装方式"。

加 `--prompt` 打印完整提示词。

> 有两段是**故意**不进聊天提示词的：天气和待回访（都只在主动开口时给）。
> `doctor` 用 scope 字段区分"故意不给"和"忘了给"——不区分的话会一直误报，
> 喊多了这个工具就没人看了。

## 开机自启与守护（重要）

**没有这一步，电脑重启后服务就不会自己起来**，而且你不会发现——除非注意到它一整天没找你。

用一个启动脚本管理，它同时负责：找 node、设工作目录、重定向日志、注册计划任务。

```powershell
.\start-friend.ps1 -Status      # 看状态（服务在不在、有没有注册自启）
.\start-friend.ps1             # 前台启动（看得到日志，Ctrl+C 停）
.\start-friend.ps1 -Background # 后台启动（日志写进 logs\）
.\start-friend.ps1 -Install    # 注册开机自启（需要管理员）
.\start-friend.ps1 -Uninstall  # 取消开机自启（需要管理员）
```

**注册自启**：开始菜单搜 PowerShell → 右键 → **以管理员身份运行** → 执行

```powershell
cd D:\PYF\friend
.\start-friend.ps1 -Install
```

装上之后：

- **登录 Windows 时自动启动**，不用手动开
- **挂了会自动重拉**（每 5 分钟检查一次）
- 日志写在 `logs\friend-日期.log`，出问题先看它

> 如果提示"无法加载脚本，因为在此系统上禁止运行脚本"，说明你的 PowerShell 执行策略是 Restricted。
> 临时绕过：`powershell -ExecutionPolicy Bypass -File .\start-friend.ps1 -Status`
> 或永久放开当前用户：`Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`

## 自动备份

`data/` 里那 200 多条对话和它对你的记忆，是**唯一无法重新生成**的东西——
代码可以重装、配置可以重填，这些丢了就没了。

服务每天会自动备份一次，备份放在 **`backups/日期/`**（独立于 `data/`，所以误删 `data/` 也不会连带删掉备份）。

```powershell
node src/cli.js backup           # 看有哪些备份
node src/cli.js backup --now     # 立刻备一份
```

保留最近 **14 天**，同一天重复备份按日期覆盖，不会堆成一堆。

**恢复方法**：停掉服务，把某份备份里的文件复制回 `data/`，再启动。

```powershell
.\start-friend.ps1 -Status          # 先确认服务状态
# 停掉服务后：
copy backups\2026-09-20\messages.jsonl data\
copy backups\2026-09-20\memory.md data\
copy backups\2026-09-20\persona.md data\
```

### 测试

```powershell
npm test                  # 全部（17 个套件，约 9 秒）
node test/all.js          # 同上
node test/prompts.js      # 单独跑某一个
```

测试分两类：**离线**（不调模型、不依赖服务，随时可跑）和**在线**（需要服务在跑）。

测试**绝对不会碰到你的真实数据**。每个测试文件的第一个 import 都是
`test/_bootstrap.js`，它把 `FRIEND_DATA_DIR` 指到一个隔离目录：

- 跑 `npm test` → 所有套件共用 `test/tmp/`
- 单独跑某个文件 → 各自用 `test/tmp-<套件名>/`

这两类目录都在 `.gitignore` 里（里面会复制真实的 `persona.md` / `memory.md`，
属于私密内容，**不要提交**）。

> 这条不是多虑：曾经直接跑 `node test/life.js` 把真实的生活设定
> 写成了测试夹具，聊天里的她一度"失去了身份"。`test/regressions.js`
> 现在会检查每个测试文件都引入了引导模块。

### 推送相关

```powershell
node src/cli.js test-bark         # 发一条固定文案，只测通道通不通
```

要确认推送到达手机时的样子，就用 `test-bark`——**它推的是写死的文字，绝不碰聊天记录**。

> 这里原本还有 `bark-last` / `bark-preview` 两个命令（把聊天记录里的消息推过去预览效果）。
> 已经删掉：它们会把**你自己说的话**推回给你，调试时反复执行就会连收十几遍。
> 你真机上收到过自己发的消息，就是它们干的。
>
> 现在**唯一会推送的路径是真实的主动消息**。测试环境还会额外挂一把总闸
> （`FRIEND_NO_PUSH=1`），让测试在物理上不可能响你手机。

## 文件在哪

```
D:\PYF\friend\
├─ config.json           ← 密钥、端口、主动策略（含访问口令，别外传）
├─ data\
│  ├─ messages.jsonl     ← 全部聊天记录，只追加，不会因崩溃损坏
│  ├─ state.json         ← 已读到哪、主动排期、连发计数、表情包用量
│  ├─ persona.md         ← 人设（它是谁，锁死，不会自动改）
│  ├─ memory.md          ← 长期记忆（关于**你**的）
│  ├─ summary.json       ← 历史摘要
│  ├─ life.md            ← 它过着什么日子（职业、住哪、作息）
│  ├─ life.jsonl         ← 它经历过的事，只追加
│  ├─ life-arcs.json     ← 它最近在推进的几件事
│  ├─ self.md            ← 它对自己的看法（**会自己慢慢变**）
│  ├─ self-changelog.jsonl ← 它改过自己什么
│  ├─ self-snapshots\    ← 每次改动前的快照，能一直往回退
│  ├─ stickers\          ← 表情包图片，你往里丢
│  ├─ stickers.json      ← 表情包索引和描述
│  ├─ weather.json       ← 天气缓存（15 分钟有效，断网时用它兜底）
│  ├─ recall.json        ← 待回访的事（"过几天该问问"的清单）
│  ├─ images\            ← 聊天里的图片（按日期分目录）
│  └─ push.log           ← 推送记录，排查推送问题用
├─ backups\              ← 每日自动备份
├─ public\               ← iPhone 端页面
├─ src\                  ← 服务端代码
├─ test\                 ← 测试
└─ tools\                ← 排查用的小脚本（编码检查、发布前查密钥、数据恢复）
```

删掉整个 `data\` 就是"重新认识一次"。删 `messages.jsonl` 但留着 `memory.md` 是"忘了聊过什么，但还记得你"。

**哪些文件是"不可再生"的**（丢了就真没了）：`messages.jsonl`、`memory.md`、`life.jsonl`、
`self.md`、`self-changelog.jsonl`、`self-snapshots\`、`recall.json`。这些都在自动备份范围内。
`images\` 和 `stickers\` 里的图**不备份**（那是你自己放的，而且会让备份迅速膨胀）。

## 搬到云服务器（电脑不常开时）

代码是按平台无关写的，全部支持环境变量，云上不用落配置文件：

```bash
DEEPSEEK_API_KEY=sk-xxx \
BARK_KEY=你的key \
FRIEND_PORT=8787 \
FRIEND_ACCESS_TOKEN=换个好记的口令 \
node src/server.js
```

用 systemd / pm2 / Docker 常驻即可，`data/` 挂个卷持久化。
搬上去之后建议：

- 关掉公网直连，或者前面挂一层 HTTPS 反代（口令是明文传输的）
- 或者只在内网跑，靠 Tailscale / WireGuard 进去

详细步骤见 `docs/部署与迁移.md`。

## 安全提醒

- `config.json` 里有你的 DeepSeek Key、Bark Key 和访问口令，**不要提交到 git、不要发群里**（`.gitignore` 已经屏蔽）
- 服务默认监听 `0.0.0.0`，也就是同局域网都能访问到端口。有口令拦着，但口令是明文传输的
- 如果电脑在不可信网络里（公司、公共 WiFi），把 `config.json` 的 `host` 改成 `127.0.0.1`，然后用 Tailscale 之类的方式进
- Bark Key 泄露了别人能给你推消息，去 Bark App 里重置即可
